# Duelo Brasa — estrutura inicial organizada

## Como testar
1. Abra esta pasta no VS Code.
2. Abra `index.html` no navegador (ou use a extensão Live Server).
3. Teste o botão **Lutar**, os controles e uma partida completa.

## Importante
Nesta primeira etapa, a lógica original continua inteira em `js/main.js`.
Os arquivos em `js/game/`, `js/story/` e `js/characters/` são apenas espaços preparados
para a próxima etapa. Não os importe ainda: vamos extrair as funções gradualmente
e testar após cada mudança.

A versão original deve ser guardada separadamente como backup.
